# ZoroCoding 严格黑绿主题设计

日期：2026-07-28
状态：用户已批准
目标版本：0.2.x

## 1. 目标

把 ZoroCoding 的应用界面统一为严格黑绿主题：

- 所有应用背景使用纯黑 `#000000`。
- 所有应用文字、边框、图标和进度视觉使用荧光绿 `#C9FF62`。
- AI 输出、终端输出、代码解析和代码差异统一为黑底绿字。
- 应用控制范围内不再出现白、灰、红、黄、蓝等第三种颜色。
- 不改变现有核心链路、模型配置、ORICO 存储约束或安全边界。

## 2. 范围

主题覆盖以下界面：

- 应用根页面和启动首帧。
- 左侧项目与任务导航。
- 项目空状态和工作台。
- 新任务、授权和模型配置弹窗。
- 模型列表、表单、输入框、下拉框和按钮。
- 任务进度、倒计时、任务步骤和历史记录。
- AI 结果、终端日志、代码块、差异视图和错误详情。
- 滚动条、焦点环、文本选区、占位文字和禁用状态。
- 应用标题栏周围的可控背景。

不在本次范围内：

- macOS 自己绘制的交通灯窗口按钮；继续保留以维持熟悉的关闭、最小化和全屏操作。其周围标题栏背景必须为黑色。
- Chromium 开发者工具。
- 外部网站、文件选择器和系统授权弹窗。
- 业务流程、模型调用协议和任务执行逻辑。

## 3. 颜色契约

应用只定义两个颜色令牌：

```css
--zoro-black: #000000;
--zoro-green: #c9ff62;
```

规则：

1. 不允许其他十六进制、RGB、HSL、命名色或渐变。
2. 不使用透明度制造灰色或浅绿色。
3. 不使用阴影；层级通过绿色边框宽度、线型和留白表示。
4. 图标必须继承当前文字颜色，不允许自带填充色。
5. SVG、伪元素、浏览器控件和焦点状态都受同一契约约束。
6. `color-scheme` 设为 `dark`，窗口首帧背景设为纯黑，避免启动时白色闪烁。

## 4. 交互状态

状态不依赖第三种颜色：

| 状态 | 表达方式 |
| --- | --- |
| 默认 | 黑底、绿字、绿色细边框 |
| 悬停 | 绿底、黑字 |
| 选中 | 绿底、黑字、绿色外框 |
| 键盘焦点 | 黑底绿字、双层绿色焦点环 |
| 禁用 | 黑底绿字、绿色虚线边框、禁止光标；不降低透明度 |
| 成功 | `✓ 成功` 标签与绿色实线边框 |
| 警告 | `△ 警告` 标签与绿色虚线边框 |
| 错误 | `✕ 错误` 标签与绿色双线边框 |
| 等待 | `… 等待` 标签与绿色点状边框 |

按钮规则：

- 主按钮：绿底黑字。
- 次按钮：黑底绿字、绿色边框。
- 危险按钮：仍为黑底绿字，以 `✕` 图标、明确文案和双线边框表达风险。

## 5. 输出与代码显示

所有输出区域使用黑底绿字和等宽字体：

- AI 结果正文保持可换行、可选择、可复制。
- 代码块、行号、语法标记和内联代码全部使用绿色，不引入多色语法高亮。
- 新增行以 `+` 前缀和左侧实线表示。
- 删除行以 `−` 前缀和左侧双线表示。
- 上下文行以空格前缀和左侧点线表示。
- 终端标准输出和错误输出都使用绿色；错误输出增加 `✕ 错误` 标签。
- 长输出继续保留滚动、换行和复制能力。

## 6. 组件与实现边界

### 6.1 主题令牌

`src/renderer/styles.css` 作为唯一颜色来源。现有颜色变量映射到两个新令牌，随后清除所有硬编码颜色、渐变、透明背景和阴影。

### 6.2 组件状态

现有 React 组件继续负责语义和状态，不在组件中直接写颜色。必要时增加状态类名或 `data-status` 属性，让 CSS 使用线型、图标和标签区分状态。

重点组件：

- `Sidebar`
- `EmptyState`
- `Workbench`
- `ProgressPanel`
- `NewTaskDialog`
- `ApprovalDialog`
- `ProviderDialog`
- `SettingsView`

### 6.3 窗口首帧

Electron `BrowserWindow` 的背景色设为纯黑，标题栏内容区域与页面根元素保持黑色，避免页面加载前出现白色区域。

### 6.4 数据与安全

主题改造不修改：

- API Key 的加密文件格式。
- 模型配置数据库结构。
- preload 沙箱与 IPC 允许列表。
- ORICO 固定存储路径。
- 高风险操作确认机制。

## 7. 自动验证

采用测试驱动开发，先增加会失败的主题契约测试，再修改生产代码。

自动验证包括：

1. 静态扫描渲染器样式，除 `#000000` 和 `#C9FF62` 外出现任何颜色即失败。
2. 禁止 `rgb()`、`rgba()`、`hsl()`、`hsla()`、命名色、渐变和非 `1` 的透明度。
3. 验证根页面、弹窗、表单、进度、输出和代码区域都引用主题令牌。
4. 验证成功、警告、错误和禁用状态不依赖第三种颜色。
5. 验证窗口配置的启动背景为纯黑。
6. 运行现有渲染器、主进程、端到端、安全门禁和发布测试。
7. 构建后在 ORICO 上实机检查：
   - 主页面无白色区域。
   - 设置和弹窗无第三种应用颜色。
   - 输出、终端和代码区域为黑底绿字。
   - 进度条和倒计时可读。
   - 开发者控制台无错误。

## 8. 完成标准

同时满足以下条件才视为完成：

- 应用控制范围内的可见界面只使用纯黑与荧光绿。
- 所有原有功能和安全测试通过。
- 9 个已配置模型仍存在，KIMI K3 仍为默认。
- API Key 仍以 macOS 安全存储加密并留在 ORICO。
- 新版本成功替换 `/Volumes/ORICO/ZoroCoding.app`。
- 0.1.0 备份和 ORICO 数据目录保持不变。
- 实机截图和控制台检查通过。
